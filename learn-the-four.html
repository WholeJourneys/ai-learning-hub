How this page stays current

Every two weeks the four platforms' official release notes are re-read and this page is rebuilt. Each pass looks for four things, in this order:

  1. A feature these guides teach being replaced or retired — the change most likely to make a step wrong.
  2. Price and plan-name changes.
  3. Announced shutdown dates and deadlines.
  4. New abilities that save a small operator real time.
