Using ChatGPT effectively

Choose the thinking level, use the right workspace, and get dependable results. Practical starting points for travel advisors, tour operators and tourism boards.

Updated9 October 2026
Next update22 October 2026

1. Match the thinking level to the job

Start with Instant for speed, Medium for most substantive tasks, and High when accuracy needs deeper cross-checking.

InstantQuick questions, rewrites, formatting, brainstorming, short replies.
MediumEveryday professional work: email, itineraries, summaries, straightforward research.
HighMulti-source comparisons, detailed logistics, data reconciliation, complex planning.
Extra High / ProWhen availableEspecially demanding analysis, coding or stubborn technical problems.

2. Habits that improve results

Give the source

Attach the itinerary, supplier quote, spreadsheet or exact link. Ask it to distinguish verified facts from assumptions.

Define the output

Specify audience, format, date, constraints, level of detail, and whether sources must be checked.

3. Chat, Work or Codex?

Work is on paid plans only. It is not available on Free or Go, and it cannot be used inside a project set to project-only memory.

Chat

Questions, drafts, research, PDFs.

Work

Longer jobs across sites, apps and files. Paid plans only.

Codex

Code, tests, repositories and debugging.

5. Connected tools: use them when they help

Daily work

  • Gmail + Calendar: client responses and schedules.
  • Google Drive / Dropbox: source files.
  • Web search: current transport, rules and rates.

Specialist workflows

  • Airtable: supplier databases.
  • Canva: branded graphics.
  • Supabase + GitHub: apps and data.
  • Todoist: follow-up tracking.
Always confirm reservations, pricing, schedules, entry rules, and medical or safety details against primary sources.

7. How to step up without starting again

1

Try Instant or Medium.

2

Request missing evidence and checks.

3

Switch to High if reasoning remains weak.

8. When to continue, and when to start fresh

Keep this chat

You are revising the same trip, answering a follow-up, or relying on details already in context.

Start a new chat

You are changing tasks, the thread has become confused, or completed work needs a clean next phase.

9. A reliable four-step handoff

1. Request a handoff

Ask for goals, decisions and WHY, rejected options, constraints, files, current status and next actions.

2. Save the actual artifacts

Store working documents, spreadsheets, images and exports in the Project or Drive.

3. Begin the next chat

Keep it in the same Project where relevant; paste the handoff and attach critical files.

4. Name and version it

Example: Menorca Guide - Hotel Mapping - Part 2 - Oct 2026. Keep prior threads.

10. Projects, memory, Space and Work are different

Project

Shared context across related chats and files.

Memory

Useful longer-term preferences and context.

Work

Multi-step execution. Not a substitute for a handoff record.

Space

Replaced Library on 29 September for accounts that have it. Projects stay separate. check your picker

11. Example: a nine-day coastal walking itinerary

Three bases, luggage transfers, variable daily distances, optional rest days and ferries. The team must preserve decisions AND reasoning between chats.

12. Prompt: create a handoff before leaving the chat

Create a one-page handoff for a new ChatGPT chat. Include the goal; decisions and why; rejected options and why; lodging and transfer constraints; layout and style rules; what is complete; unresolved questions; exact filenames; and the next action. State anything you could not verify.

13. Prompt: extract a reusable playbook

Using this finished itinerary, make a reusable tour-design playbook without client-identifying information. Specify daily layout, pacing rules, decision criteria for hotels and transfers, alternatives, verification checks, and reasons for each rule. Save it as version 1.
